# Calculadora de Promedio

## Descripción
Este proyecto consiste en una página web sencilla que permite ingresar tres notas y calcular automáticamente su promedio.

## Objetivo
El objetivo es desarrollar un proyecto simple de programación para aplicar conceptos básicos de Git y GitHub, como control de versiones, commits, ramas, issues y pull requests.
