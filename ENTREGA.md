Primero armé el proyecto y lo inicié con Git. Fui agregando los archivos y haciendo commits a medida que avanzaba. Después subí el proyecto a GitHub y trabajé con una rama para hacer una mejora. Finalmente hice la pull request y pasé los cambios a la rama principal.
